A321 — 3D-модель самолёта

A321 — интерактивный инженерный конструктор самолёта. Поворот 3D-модели, выбор варианта двигателя и схемы салона, расчёт массы и ограничений.

Доступные варианты

  • CFM56-5B · 220 мест · одноклассная · 220 мест
Компоновки салона являются плановыми пресетами инженерной модели, а не утверждёнными LOPA эксплуатантов. Числа расчёта не заменяют сертифицированные характеристики.
