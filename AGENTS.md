# Локальное согласование агрегатов

Для пакетов детализации OpenAircraftCreator в итоговом ответе давай только ссылки на проверенные страницы локального запуска. Подписывай ссылки типом ВС, модификацией и агрегатом. Для подвижного узла открывай страницу на середине хода. Изображения и подробный отчёт присылай по отдельной просьбе владельца.
