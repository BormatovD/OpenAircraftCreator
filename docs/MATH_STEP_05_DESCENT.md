# Математика — шаг 05: снижение и заход A320ceo (CES)

**Дата:** 12 ноября 2026 года. **База:** установленный пользователем `MATH_STEP_04`.

## Что подключено

Только для неизменённого `A320CEO` (A320-214 / CFM56-5B4/P SAC, fence) и только при профиле M0,78/300/250 kt, ISA0, NORMAL A/C, anti-ice OFF используется набор `data/fcom/a320-214-ces-phases.json` из China Eastern FCOM, Volume 3, PDF-страница **1846**, код **3.05.30 P2 SEQ170 REV27**. Снижение считается от конечного эшелона крейсера до **FL15** (1500 ft). Для захода и посадки добавляются **120 кг**, 6 минут IFR из FCOM Volume 2, PDF-страница **647**. Прежние 300 кг при покрытой точке не добавляются.

### Важное ограничение WEIGHT

В заголовке исходной таблицы указано `WEIGHT (1000KG)`, но **не сказано**, является ли это массой в начале, конце или середине снижения. Мы используем **оценочную массу на FL15** = `takeoffMassKg - tripFuelKg + approachFuelKg` (то есть после pure descent, перед заходом). Это обозначено в `TripResult.descentMassBasis` как `estimated-mass-at-1500ft`. Это **допущение модели**, не установленный факт FCOM. Не использовать как эталон без дополнительного подтверждения применимости.

Дистанция захода **не приведена** в использованной табличной строке FCOM. Для первого рабочего приближения отдельно задана `fcomApproachGroundspeedKt = 135 kt`, что при 6 мин даёт **13,5 nm**. Это предположение без ветра, а не документированное значение. Физическая оценка общего рейса будет чувствительна к нему; не использовать эту величину для подгонки TSFC.

## Контрольный пример

Чистый расчёт по таблице (все массы для интерполяции задаются явно): **60 т, FL350**, ISА, NORMAL A/C, anti-ice OFF:

- FCOM pure descent: **150,5 кг**, **90,5 nm**, приблизительно 15,225 мин.
- FCOM IFR approach + landing: **120 кг** за 6 мин; дистанция в источнике не указана.
- Суммарное топливо: **270,5 кг**; модельная дистанция: **104,0 nm** (90,5 + 13,5; последние 13,5 nm — оценка).

Реальный `simulateTrip` выбирает строку таблицы по *конечной* высоте крейсера и оценочной массе на FL15: это не обязательно FL350/60т. При ступенчатом наборе в крейсере расчёт повторяется при изменении верхнего эшелона снижения до стабильного топливного бюджета. При отсутствии стабильного решения или покрытой ячейки используется физическая модель, с `descentSource`.

## Ограничения применения и регрессия

- Нельзя использовать для A319, A321, NEO, перепроектированного A320, изменённых рычагов, другого Маха/температуры или запасного аэродрома.
- Нельзя экстраполировать за массу 45–65 т и высоту FL15–FL390.
- Короткий рейс, не включающий полный набор/снижение, сохраняет прежний физический расчёт (`energy-short-route`).
- Разделение массы фиксируется в результатах, а не скрывается в коэффициентах двигателя.
- TSFC **0,586 lb/(lbf·h) не изменялся**.
- Восстановленная локальная среда прошла **6 новых тестов** снижения и разбор исходного JSON без экстраполяции. **Полный `npm test` актуальной ветки должен быть выполнен после применения.**

## Что делаем

1. Подтвердить у специалистов смысл `WEIGHT` на странице 1846 (начало / конец / средняя масса снижения).
2. Подтвердить модельную скорость и дистанцию 6-минутного захода либо заменить её трассой захода.
3. Применить отдельный патч ожидания, затем повторно посчитать полный топливный бюджет.
4. Не перекалибровывать TSFC по этим не полностью определённым условиям.
