# Пассажирские салоны Airbus и Boeing

Количество мест, классы и неполные ряды берутся из выбранной компоновки общего каталога FlightCost. Для 737-300 применяется смешанный салон на 128 мест из Boeing D6-58325-6. Продольные проходы, кухня с тележками, туалетные блоки, секции багажных полок и шаг кресел в 3D подогнаны к текущей обшивке. Точная привязка мебели к шпангоутам конкретного борта требует его LOPA.

| Семейство | Основание для эскиза |
| --- | --- |
| A319 и A320 | Airbus показывает один проход, кухонные модули в носу и хвосте, передний и задние туалеты. Компактный задний блок варианта A320neo на 194 кресла ориентирован на опубликованный пример SpaceFlex. [A319 AC, 2-4-1](https://www.aircraft.airbus.com/sites/g/files/jlcbta126/files/2025-07/AC_A319_20250715.pdf) · [A320 AC, 2-4-1](https://www.aircraft.airbus.com/sites/g/files/jlcbta126/files/2023-12/ac_a320_1223.pdf) · [Airbus, A320 на 194 места](https://www.aircraft.airbus.com/en/newsroom/press-releases/2021-08-avianca-selects-airbus-services-for-their-cabin-reconfiguration) |
| A321 | Для 220 мест выбран стандартный вариант. Для A321neo на 244 места использованы контуры выходов Cabin Flex, включая два надкрыльевых выхода с каждого борта. [A321 AC, 2-4 и 2-7](https://www.aircraft.airbus.com/sites/g/files/jlcbta126/files/2025-01/AC_A321_0624.pdf) |
| 737 Classic | Образец на 128 мест состоит из 8 кресел первого класса с шагом 36 дюймов и 120 кресел экономкласса с шагом 32 дюйма. В интерфейсе передний класс входит в общую категорию «бизнес». Один надкрыльевой выход на борту. Его станция в модели приближённая. [Boeing D6-58325-6, 2.4.7](https://www.boeing.com/content/dam/boeing/v2/airports/acaps/737CL_REV_E.pdf) |
| 737-800 и MAX | У NG и MAX оборудование размещено в переднем и заднем служебных блоках. Плотный пресет MAX с 210 местами использует выходы 737-8-200. Станция дополнительного выхода по табл. 2.7.1 — 25,20 м, пересчитана в масштаб геометрии проекта. Наружный габарит его створки оценочный. [Boeing D6-58325-7, 2.4](https://www.boeing.com/content/dam/boeing/v2/airports/acaps/737NG_REV_C.pdf) · [Boeing D6-38A004, 2.4 и 2.7.1](https://www.boeing.com/content/dam/boeing/v2/airports/acaps/737MAX_RevK.pdf) |
| 757-200 | Проходы и служебные зоны привязаны к установленным в модели дверям. В обеих моторизациях используется вариант с надкрыльевыми выходами. В компоновке на 186 мест распределение по классам взято из каталога проекта. Операторские планы на 225 и 239 мест требуют дополнительной сверки по конкретному борту. [Boeing D6-58327, 2.4.1](https://www.boeing.com/content/dam/boeing/v2/airports/acaps/757_Rev_H.pdf) |

При изменении длины фюзеляжа пересчитываются ряды и защищённые зоны перед выходами. Когда кресла с исходным шагом не помещаются между ними, панель осмотра показывает уменьшенный эскизный шаг. Число мест, масса и параметры расчёта используют исходную конфигурацию. Модель служит для осмотра агрегатов и не оценивает эвакуацию или сертификационное соответствие компоновки.
