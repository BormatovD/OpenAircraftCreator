# OpenAircraftCreator — расчётное ядро

Фаза 1: миссия, калибровка по диаграммам нагрузка–дальность A320ceo/neo, массовая сводка по агрегатам и каркас рычагов.

## Запуск

Нужен Node ≥ 22.18 (TypeScript исполняется без сборки, типы снимаются встроенно).

```
npm install          # только TypeScript и типы Node для проверки типов
npm test             # 27 тестов: миссия, калибровка, массы, рычаги, CEO → NEO, ограничения, перепроектирование
npm run calibrate    # миссия против диаграмм Airbus; отчёт в out/calibration-a320.json
npm run masses       # дерево масс по агрегатам и проверка на NEO
npm run levers       # эффект рычагов на OEW, дальность и расход на место
npm run constraints  # ограничения по сценариям
npm run redesign     # «та же геометрия» против «перепроектировать под ту же миссию»
npm run dev          # 3D-модель в браузере с живой перезагрузкой (http://localhost:5173)
npm run build        # один офлайн-файл dist/index.html
npm run typecheck
```

## Принцип калибровки

Аэродинамика закреплена по литературе (Poll & Schumann: CD0 ≈ 0,019, e ≈ 0,78).
Калибруется один параметр — крейсерский TSFC. Массы в углах диаграмм берутся из самих
графиков, поэтому проверка изолирует аэродинамику, двигатель и миссию от массовой сводки.

## Результат (A320)

Крейсер — ступенчатый набор: самолёт занимает самый высокий эшелон из FL290–390, где CL ≤ 0,59
(расчётный оптимум A320 по Poll & Schumann); подъём на ступень оплачивается топливом.

| | TSFC, lb/(lbf·h) | RMS ошибки | Макс. ошибка |
| --- | --- | --- | --- |
| CEO с шарклетами (подгонка) | 0,587 | 0,7% | 1,1% |
| NEO (подгонка) | 0,499 | 2,0% | 3,5% |
| CEO с «заборчиками» (проверка без подгонки) | 0,587 | 0,6% | 1,2% |

- TSFC NEO/CEO = 0,849 — согласуется с заявленной экономией ≥15%.
- TSFC CEO отличается на −0,5% от независимой оценки по общему КПД η_o = 0,309 (Poll & Schumann).
- Остаток NEO: угол «макс. нагрузка» на 73,5 т даёт +3,4%, на 79 т — −3,5%. Знаки противоположны
  у одинаковых углов, поэтому вероятнее неточность данных (оцифровка или разные весовые варианты
  в графиках), а не модели: у CEO те же углы сходятся в пределах 1%.
- Режим "fixed" (постоянный FL350) оставлен для сравнения: с ним RMS был 2,3–2,4%, перегонка занижалась на 2–5%.

## Допущения миссии

Все в `DEFAULT_ASSUMPTIONS` (`src/mission.ts`): M 0,78, ступенчатый набор FL290–390 при CL ≤ 0,59; запасной 200 nm на FL250;
5% на непредвиденное; 30 мин финального резерва; руление 200 кг; набор 190 км; снижение 300 кг / 180 км.

## Массовая сводка

Публичной групповой сводки A320 нет. Поэтому:
1. **Чувствительность** — из формул Raymer: как масса агрегата зависит от размаха, площади, MTOW и т. д.
2. **Базовый уровень** — доли групп у ближайшего узкофюзеляжника с фактическими данными (737-200),
   отнормированные на OEW A320 из Airbus AC. Двигатели, шарклеты и оборудование эксплуатанта задаются напрямую.
3. **Проверка без подгонки** — NEO = CEO + шарклеты + LEAP-1A с гондолами, масштабированными по диаметру
   вентилятора. Модель: 43 011 кг, Airbus AC: 43 144 кг (−0,3%). Разница NEO − CEO: 1 767 против 1 900 кг.

Надёжность разбивки: крупные группы (крыло ≈7,3 т, фюзеляж ≈8,4 т, шасси ≈3,0 т) правдоподобны — крыло
попадает в разброс методов из работы HAW Hamburg (3,3–9,1 т, среднее 6,2 т). Разбивка внутри бортовых систем —
слабое место: аналог из 1960-х, множители отдельных систем от 0,4 до 7. Абсолютная масса электрожгутов (≈370 кг)
скорее занижена; рычаги на них корректны по доле, но не по килограммам.

## Как расширять

- **Новая система или агрегат** — запись в `NODES` (`src/mass/massTree.ts`): id, глава ATA, родитель, функция оценки.
  Чтобы узел участвовал в калибровке, добавьте его в группу аналога в `GROUP_MAP`.
- **Новый рычаг** — запись в каталоге `src/levers.ts`. Эффекты: `definition` (геометрия, двигатель),
  `massFactor` / `massDelta` (любой узел или группа — действует на потомков), `aero` (CD0, Освальд, общее
  сопротивление), `engine` (TSFC). Расчёт менять не нужно.

## Фаза 2, шаг 1: двигатель и фюзеляж

**Двигатель.** Общий КПД = термический (ядро) × пропульсивный (вентилятор), TSFC = V / (η_th · η_p · LHV).
- Пропульсивный КПД от двухконтурности: ядро отдаёт удельную работу w, её делит поток (1 + B);
  V_j = √(V² + 2w/(1+B)), η_p = 2V/(V + V_j).
- Термический КПД — идеальный цикл Брайтона по степени сжатия × множитель прочих технологий ядра.
- Разделение выигрыша NEO — допущение: ядру приписан только рост степени сжатия 32,6 → 40 (+3,3%),
  остальное — вентилятору. Отсюда w ≈ 539 кДж/кг, η_p ≈ 0,67 → 0,76 (с шага 10 — 753 кДж/кг, 0,61 → 0,71, см. ниже). Степень сжатия CFM56-5B в источниках
  27–35,5; от этого η_p CEO гуляет 0,62–0,76 — это главная неопределённость рычага.
- Диаметр вентилятора и масса двигателя — линии по CFM56-5B и LEAP-1A. PW1100G (B 12,5, ≈2,05 м)
  ложится на линию диаметра без подгонки. Масса — по прямоприводным; редукторный PW1100G легче линии.

**Фюзеляж.** Целые ряды: +6 мест на ряд при шаге 29 in. Растут масса фюзеляжа, объём гермокабины, салон,
плечи оперения. MTOW и MZFW не меняются (режим «та же геометрия») — поэтому при удлинении быстро упираемся в MZFW.

**Критерий фазы 2 выполнен:** определение NEO целиком (двигатели + шарклеты + массы) даёт −15,6% топлива
на место против CEO; Airbus заявляет не менее 15%. TSFC здесь совпадает по построению (калибровка),
а массы, шарклеты и миссия — предсказание.

| Рычаг (на A320ceo) | ΔOEW | TSFC | Дальность со всеми местами | На место |
| --- | --- | --- | --- | --- |
| Двухконтурность 5,7 → 11 | +1 500 кг | −12,2% | +1,4% | −10,5% |
| Двухконтурность 5,7 → 15 | +2 640 кг | −16,6% | +0,8% | −14,2% (упор в MZFW) |
| Ядро: степень сжатия 32,6 → 40 | 0 | −3,2% | +4,0% | −3,2% |
| Фюзеляж +3 ряда (198 мест) | +773 кг | 0 | −19,6% | −7,0% (упор в MZFW) |
| Фюзеляж −3 ряда (162 места) | −777 кг | 0 | +23,8% | +6,5% |
| A320neo целиком | +1 767 кг | −15,0% | +7,1% | −15,6% |

## Фаза 2, шаг 2: ограничения

| Ограничение | Как считается | Порог | Проверка |
| --- | --- | --- | --- |
| Код аэродрома | Аэродинамический размах | 36 м, ICAO Annex 14 | — |
| Клиренс гондолы | База 0,57 м (AC) − половина прироста ширины гондолы + подъём установки | ≥ 0,46 м (как у NEO); < 0,30 м — условный предел | Чистая геометрия даёт NEO 0,40 м, AC — 0,46 м: Airbus поднял двигатель ≈на 6 см (выведено) |
| Угол касания хвостом | Точка касания уходит назад на половину вставки | база 11,7°; отрыв ≈10° — допущение | Плечо 16,4 м откалибровано по A321: 9,7° (FCOM Bulletin 22/2) |
| Длина ВПП | TOFL ∝ W² / S при той же тяге | +5% / +15% — условные | База 2 180 м (Jenkinson) |
| MZFW | Все места помещаются | — | — |
| Двухконтурность | В диапазоне реальных двигателей | 5–13 | — |

Удлинение на 9 рядов (≈A321) даёт угол касания 9,8° < 10° на отрыве — модель требует «иной закрылок».
У A321 именно так: двухщелевые закрылки позволяют отрываться на меньшем тангаже.

## Фаза 2, шаг 3: перепроектирование под ту же миссию

Держим постоянными: расчётную нагрузку (все места × 95 кг) и дальность базового самолёта с ней (2 219 nm),
нагрузку на крыло, удлинение и тяговооружённость. Итерация по MTOW: геометрия и двигатели масштабируются →
массы по Raymer → топливо на миссию → новое MTOW. Масса двигателя ∝ тяге, диаметр ∝ √тяги, баки ∝ S^1,5.
MZFW = OEW + нагрузка + тот же запас, что у базы.

| Рычаг | Та же геометрия: OEW / на место | Перепроектирование: MTOW / OEW / на место |
| --- | --- | --- |
| Композитное крыло −20% | −3,6% / −2,5% | −4,1% / −5,9% / −3,8% |
| Аэродинамическое качество +5% | 0 / −3,9% | −1,7% / −1,1% / −5,1% |
| Двухконтурность 11 + ядро 40 | +3,6% / −13,3% | −1,5% / +2,6% / −13,9% |
| Фюзеляж +9 рядов | +5,6% / +3,4% (упор в MZFW) | +22,6% (90,1 т) / +19,9% / −7,1% |

Проверка: удлинение на 9 рядов сходится к MTOW 90,1 т — у A321ceo по AC 78–93,5 т. Отличие от реального A321:
модель держит нагрузку на крыло, поэтому крыло растёт до 150 м² и размаха 37,8 м (код D). Airbus оставил
крыло A320 и принял большую нагрузку на крыло, компенсировав её двухщелевыми закрылками.

## Фаза 3, шаг 1: 3D-модель в разборе

`web/` — Vite + three.js. Ядро из `src/` работает прямо в браузере: массы на выносках — те же, что в `npm run masses`.
- `web/scene/shapes.ts` — фюзеляж по сечениям (суперэллипс, сужение носа и хвоста), несущие поверхности с профилем
  NACA 00xx, гондолы и двигатели телами вращения.
- `web/scene/aircraft.ts` — модель из определения самолёта: каждый узел дерева масс — своя группа мешей,
  направление разлёта и выноска. Всё строится из размеров определения, поэтому рычаги сразу меняют форму.
- Выноски постоянно показываются у агрегатов тяжелее 2% OEW, остальные — при наведении.
- Темы: тёмная («ангар ночью») и светлая («инженерная иллюстрация»); акцент — цвет цинк-хроматного грунта.

## Фаза 3, шаг 2: рычаги, сценарии, механизация

- Геометрия по чертежу A320 (3 вида): крыло с изломом задней кромки, фюзеляж по линиям верха/низа/ширины,
  оперение привязано к концу фюзеляжа, двигатель на 11,2 м от носа и 5,65 м от оси, база и колея шасси по AC.
- Крыло в дереве масс — группа: `wing.box` (кессон, ATA 57-10…30) и `wing.highLift` (механизация и элероны,
  ATA 57-40…70). Доля механизации 18% — Torenbeek для закрылков + допущение для остального (`movablesShareOfWing`).
  Калибровка по 737-200 не изменилась: группа «крыло» делится между двумя узлами.
- Новые рычаги: `compositeHighLift`, `wingTip`, `nacelleRaise`; `compositeWing` теперь действует только на кессон.
- `web/controls.ts` — панель рычагов и сценарии как данные: значение по умолчанию берётся из выбранного самолёта,
  в ядро уходят только сдвинутые рычаги.
- Сценарии: «CEO → NEO своими руками» (сравнение с A320neo), «Композитное крыло» (перепроектирование),
  «Путь к A321».
- Справа: расход на место с дельтой к базе, плитки, диаграмма нагрузка–дальность (база пунктиром), ограничения.
  В 3D: композитные агрегаты — тёмные, агрегаты с нарушенным ограничением — подсвечены.
- Быстродействие: «та же геометрия» считается за кадр (~30–50 мс), перепроектирование (~0,4 с) — после паузы
  в движении ползунка. Контурные линии строятся с задержкой, старая модель освобождает видеопамять.

## Фаза 3, шаг 3: разрез двигателя и «Как рассчитано»

- Двигатель — разрез двухвального ТРДД (`engineCutaway` в `web/scene/shapes.ts`): вентилятор с числом лопаток
  из определения (CFM56-5B — 36, LEAP-1A — 18), подпорный компрессор, КВД, камера сгорания, ТВД, ТНД, валы НД и ВД,
  кожух ядра с вырезом, центральное тело. Радиус ядра ∝ √(1,6/(1+B)), ступени ТНД — от двухконтурности.
  Вал НД — бронзовый, вал ВД — голубой, камера — красная; роторы вращаются (ВД условно втрое быстрее НД).
  При разборе детали двигателя разлетаются вдоль оси.
- Карточка двигателя: схема продольного разреза, деление потока между контурами, валы и ступени, η_p, η_th, TSFC к базе.
- Страница «Как рассчитано» (`web/method.ts`, вкладка в шапке, адрес `#method`): формулы (KaTeX → MathML,
  без шрифтов и сети), таблицы масс и проверки по диаграммам AC считаются тем же ядром, допущения выделены,
  14 источников со ссылками. Из карточки агрегата — ссылка на нужный раздел.

## Фаза 3, шаг 4: связь рычагов и агрегатов, полёт, детали

- Наведение на рычаг (или его перетаскивание) — «рентген»: агрегаты, на которые он действует, подсвечиваются,
  остальное становится полупрозрачным стеклом. Выбор агрегата подсвечивает его рычаги в левой панели
  и даёт кнопки-переходы к ним в карточке. Связи берутся из `parts` в `web/controls.ts`.
- `web/scene/environment.ts`: земля (лоскуты полей, бесшовная текстура), полоса и облака движутся под самолётом;
  фазы «Стоянка / Взлёт / Крейсер / Посадка» плавно меняют высоту земли, скорость, выпуск шасси
  (основные стойки убираются внутрь, передняя — вперёд) и механизации (предкрылки вперёд-вниз, закрылки назад-вниз).
  По умолчанию — крейсер, самолёт собран. Переключатель «Движение» выключает анимацию; при prefers-reduced-motion она выключена.
- `web/scene/textures.ts`: окна (шаг 21 дюйм), двери, аварийные выходы над крылом, остекление кабины — текстурой
  по развёртке фюзеляжа; количество окон следует за длиной фюзеляжа.

## Фаза 3, шаг 5: геометрия по векторным чертежам Airbus AC

- `tools/ac_extract.py` (офлайн, Python + PyMuPDF): читает векторные линии разделов 2-2-0 (виды сбоку, сверху, спереди
  A320ceo и A320neo) и 2-5-0 (сечение) из PDF AC, масштабирует по подписанным размерам (37,57 м, 34,10 м, 3,95 м),
  отбрасывает размерные линии (прямые, частично вне силуэта), склеивает фрагменты → `data/ac/a320-ac.json`.
  Три вида сходятся по масштабу в пределах 0,3%.
- `tools/ac_shapes.py` → `data/ac/a320-shapes.json`: профили фюзеляжа (верх, низ, полуширина с шагом 0,25 м; наклон
  чертежа снят), сечение r(θ), план крыла (передняя кромка 27,3°, излом задней кромки на 6,64 м), стабилизатор, киль,
  окна/двери/выходы, линии механизации и рулей в долях размаха и хорды.
  Проверка: площадь крыла по извлечённому плану ≈122 м² против 122,4 м² у Jenkinson.
- Модель: фюзеляж и сечение — по таблицам AC (удлинение — две цилиндрические вставки, 8 и 25 м от носа),

## Фаза 4, шаг 1: аэродинамика ядра

- `src/drag.ts`: CD0 по составляющим (Raymer component buildup): Cf турбулентной пластины по Re агрегата на FL350,
  форм-факторы (толщина профиля, удлинение тела), интерференция (гондолы под крылом — 1,3), прочее 8%.
  Без подгонки сумма для A320 — 0,0191 против 0,019 у Poll & Schumann; уровень привязан множителем ×0,973.
- Индуктивное: e по Оберту 1/(1,05 + 0,007πA), привязан к 0,78 на A320 с шарклетами.
- Волновое: уравнение Корна (κ = 0,935, средняя t/c = корневая × 0,75) и закон Локка 20(M − Mcr)⁴.
  Mdd A320 при CL 0,55 — 0,821 (MMO 0,82). Привязка: CD0 + CDw = 0,019 при CL 0,55, M 0,78.
- TSFC от числа Маха — по Howe, нормировано на M 0,78. Оптимум расхода A320 — около M 0,76.
- Пересчёт калибровки (`npm run calibrate`): TSFC CEO 0,588 (СКО 0,8%), NEO 0,491 (2,0%), «заборчики» без подгонки 0,8%.
  NEO/CEO = 0,835 (гондола LEAP добавляет ≈5 каунтов, поэтому двигатель должен быть лучше, чем считалось с постоянным CD0);
  удельная работа ядра w = 753 кДж/кг, η_p 0,61 → 0,71. CEO → NEO рычагами: −15,5% топлива на место.
- Новые рычаги: «Толщина профиля» (волновое ↔ масса крыла ↔ объём баков), «Крейсерское число Маха».
- Справа — раскладка сопротивления в крейсере по агрегатам, индуктивному и волновому в каунтах; на странице
  «Как рассчитано» — формулы, таблица агрегатов и таблица по числу Маха.
- Интерфейс: окраска остаётся в разборе; выноски не перекрываются (лишние — при наведении); схема двигателя —
  продольный разрез с ступенями, камерой сгорания, валами и анимированными потоками.

## Фаза 4, шаг 2: двигатель вне расчётного режима

- `src/thrust.ts`: располагаемая тяга по высоте и скорости — формула Mattingly для ТРДД большой двухконтурности
  δ₀·(1 − 0,49√M). На FL350, M 0,78 — 0,199 взлётной, для CFM56-5B4 ≈5 400 lbf (порядок опубликованных крейсерских тяг).
  Зависимости от двухконтурности нет сознательно: реальные двигатели проектируют на верх набора, и цена этого уже
  в массе и диаметре с линии CFM56 → LEAP (подробно — на странице «Как рассчитано»).
- Потолок по тяге: самый высокий эшелон, где тяга покрывает сопротивление плюс 300 фут/мин. A320ceo и neo при MTOW — FL360.
  Тот же предел теперь ограничивает ступенчатый набор в миссии (базовые результаты и калибровка не изменились).
- Второй сегмент взлёта с отказавшим двигателем (CS 25.121(b), ≥ 2,4%): CEO 4,0%, NEO 4,6%. Взлётная поляра — допущения
  (CLmax 2,2, механизация +0,012, отказ +0,003); станет рычагами на шаге механизации.
- Длина ВПП теперь по фактической взлётной тяге (CFM56-5B4 27 000 lbf, LEAP-1A26 27 120 lbf).
- Новый рычаг «Взлётная тяга» (85–125%): масса двигателя ∝ тяге, диаметр ∝ √тяги. При 85%: −870 кг OEW, −1,9% топлива,
  но потолок FL320, градиент 2,1% (нарушение нормы), ВПП 2 565 м.
- Справа — график «Тяга на наборе»: располагаемая и потребная по эшелонам, потолок.
- Выделение агрегата: окраска сохраняется, агрегат обводится контуром и слегка подсвечивается вместо заливки салатовым.

## Фаза 4, шаг 3: механизация

- `src/highlift.ts`: CLmax по конфигурациям по Raymer — чистое крыло 0,9·Cl_max·cos Λ, приросты закрылков
  (однощелевой Фаулер 1,3·c'/c, двухщелевой 1,6·c'/c) и предкрылков (0,4·c'/c) на долю площади с механизацией.
  Привязка одним множителем ×1,08: посадочный CLmax A320 по скорости захода 134 уз при MLW. A320: CLmax 1,41 / 2,24 / 2,69
  (чистое / взлёт / посадка), V2 144 уз при MTOW, заход 134 уз; A320neo (MLW 66,3 т) — 136 уз.
- Новые рычаги: «Двухщелевые закрылки» (как у A321), «Хорда закрылков» 18–36%, «Предкрылки». Массы — через доли узла
  механизации (закрылки 60%, предкрылки 20% — допущение), двухщелевые ×1,25.
- Длина ВПП учитывает CLmax на взлёте; набор с отказом двигателя — V2 из CLmax; новое ограничение — скорость захода
  и категория ИКАО (C ≤ 140 уз).
- Режим «под ту же миссию» держит скорость захода, а не нагрузку на крыло: S ∝ MTOW/CLmax. Путь к A321 (+9 рядов):
  с однощелевыми закрылками крыло ≈149 м², размах 37,6 м (код D); с двухщелевыми — ≈134 м², 35,6 м (код C).
- Справа — панель «Взлёт и посадка»; подсказки при наведении на CD и L/D (что такое «каунт» и почему качество может не меняться).
- 3D: закрылки выпускаются поворотом вокруг шарнира с выдвижением назад (40° на посадке), предкрылки — носком вниз (27°);
  обтекатели кареток прижаты к нижней поверхности и наклоняются вместе с закрылками. Двухщелевой закрылок — два звена;
  без предкрылков передняя кромка становится частью кессона; хорда закрылков меняет геометрию.
